# Shop WebUI（买家端 PC 站）

零构建、零 npm 依赖的原生 **ES Module SPA**，**桌面 PC 端**中文电商买家界面，视觉与布局参考**淘宝 PC 站**（taobao.com）：宽屏 1190px 居中内容区、顶部迷你条 + 大搜索 + 橙色横向导航、左侧全部分类飞出菜单、密集多列商品网格、表格式购物车。由 nginx 同源托管并反代后端网关。

> 设计基准视口 1440×900（≥1200px 宽体验最佳）。站点不是 mobile H5：没有底部 Tabbar，没有 560px 居中手机栏。

## 启动

前置：8 个 Spring Boot 应用 + 网关已在宿主机启动（网关监听 `:8080`，见 `deploy/local/start-apps.sh`）。

```bash
docker compose -f webui/docker-compose.yml up -d
# 打开
open http://localhost:8000
```

- 静态站点：容器内 `/usr/share/nginx/html`（直接挂载本目录，改文件刷新即生效）。
- API：浏览器同源请求 `/api/**`，由 nginx 反代到 `host.docker.internal:8080`（网关），规避 CORS。
- Linux 宿主机已在 compose 中配置 `extra_hosts: host-gateway`。

## 架构约定

- `assets/js/main.js`：hash 路由表 + 登录守卫（白名单：首页/分类/搜索/商品详情/登录）。
- `assets/js/lib/shell.js`：PC 站点外壳（迷你条 / 头部搜索 / 橙色导航 / 页脚 / 内页标题栏），所有页面通过 `shell({ content, ... })` 拼装。
- `assets/js/api.js`：全部接口路径**以后端控制器源码为准**（非历史文档），统一 Result 包装（`code=0` 成功）。
- `assets/js/lib/http.js`：
  - 注入 JWT Bearer；401/403 清登录态并跳登录；
  - **大整数无损解析**：后端雪花 ID 为 19 位 Long（超出 `Number.MAX_SAFE_INTEGER`），响应文本先经扫描式转换，将字符串外 ≥16 位纯整数加引号再 `JSON.parse`，ID 一律按字符串传递。
- mock 支付回调签名：`HMAC_SHA256(secret, amountFen&channelCode&channelTxnNo&notifyId&payNo&status)`，字段按 TreeMap 字典序；密钥仅为本地开发默认值（`ChannelSecretProvider` DEV 默认值）。
- 金额单位：后端一律为「分」，前端展示用 `fen2yuan`。

## 验证

端到端用 Playwright（Chromium，**桌面视口 1440×900**）跑通两条链路，并对关键页面做 PC 布局断言（1190px 内容区、5 列商品网格、6 列购物车表格、两栏详情、无底部 Tabbar、弹窗居中）：

1. 主链路 27 步：登录卡片→注册→首页（5 列网格 + 分类飞出菜单）→分类（190px 侧栏 + 4 列商品）→搜索→详情两栏→SKU 居中弹窗加购→表格式购物车→地址→结算→下单→mock 支付签名回调→支付成功→订单列表/详情→会员/券/售后/资料→刷新登录态保持；
2. 深度链路 10 步：宽屏外壳断言→发货（测试库置状态）→物流→居中确认弹窗→确认收货→评价→提交售后→售后详情→撤销。

均无 console error、无 API 5xx。
